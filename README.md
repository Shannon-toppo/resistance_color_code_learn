# 抵抗カラーコード学習アプリ

抵抗器のカラーコード(4本帯)を覚えるための学習アプリです。ブラウザだけで動く単一HTMLファイルで、インストール不要・スマホ対応です。

**▶ 公開ページ: https://shannon-toppo.github.io/resistance_color_code_learn/**

## 機能

- **クイズ: 色→値** — カラーバンドを見て抵抗値を入力して回答(単位は Ω / kΩ / MΩ から選択)
- **クイズ: 値→色** — 指定された抵抗値になるようにバンドをタップして塗る
- **早見表** — カラーコード対応表と、バンドをタップすると値がリアルタイムに変わるインタラクティブな抵抗器
- **語呂合わせ** — 「黒い礼(0)服」などの語呂カードで暗記(数字を隠すフラッシュカード式)

クイズの出題は **E12系列(実在値)** と **乱数(練習用)** を切り替えられます。スコア(連続正解・正答率)はブラウザに保存されます。

## 使い方

公開ページを開くだけです。ローカルで使う場合は `index.html` をブラウザで開いてください。

## その他

- フレームワーク・外部ライブラリ不使用(プレーンHTML/CSS/JS)
- ダークモード対応(OS設定に自動追従、手動切替も可)
